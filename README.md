# 🌐 Plataforma Web Corporativa - Vidatur

Plataforma web desarrollada para la **publicación y gestión de contenido turístico, comercial y de marketing digital**, con un enfoque especial en diseño responsive y experiencia de usuario.

El proyecto integra diferentes módulos para programas turísticos, campañas, eventos, formularios, socios estratégicos y contenido comercial, permitiendo organizar la información dentro de una estructura web modular.

## 🎯 Objetivo

Desarrollar una plataforma web corporativa que permita presentar y organizar contenido turístico y comercial de manera clara, moderna y adaptable a distintos dispositivos.

El proyecto busca mejorar la experiencia de navegación del usuario y facilitar la publicación de información relacionada con productos, programas, campañas y servicios turísticos.

---

## 📱 Diseño Responsive

Uno de los principales enfoques del proyecto fue adaptar las diferentes páginas y componentes para ofrecer una correcta visualización en:

* Computadoras de escritorio.
* Laptops.
* Tablets.
* Dispositivos móviles.

Se realizaron ajustes en estructura, navegación, distribución de contenido, imágenes y componentes visuales para mantener una experiencia consistente entre dispositivos.

---

## 📢 Marketing y contenido digital

La plataforma está orientada también al soporte de actividades comerciales y de marketing mediante la publicación de:

* Programas y productos turísticos.
* Campañas comerciales.
* Eventos.
* Formularios de contacto y captación.
* Socios estratégicos.
* Contenido nacional e internacional.
* Información promocional.
* Recursos visuales y piezas digitales.

Esto permite utilizar el sitio web como un canal de comunicación y apoyo para las acciones comerciales de la empresa.

## 🧩 Módulos principales

### 🌎 Nacional

Gestión y presentación de productos y programas turísticos nacionales.

### ✈️ Internacional

Publicación de información relacionada con destinos y programas internacionales.

### 📅 Eventos

Organización y presentación de eventos y contenido promocional.

### 📝 Formularios

Captura de información y solicitudes realizadas desde el sitio web.

### 🤝 Socios estratégicos

Presentación y organización de información de aliados comerciales.

### 👥 Equipo

Contenido relacionado con el equipo y la información corporativa.

## 📂 Estructura general

```text
vid-demo/
│
├── config/
├── css/
├── cuentas_bancarias/
├── equipo_vidatur/
├── eventos/
├── formularios/
├── img/
├── includes/
├── interfaces/
├── international/
├── js/
├── lib/
├── nacional/
├── socios_estrategicos/
│
├── .htaccess
└── 404.php
```

La organización por módulos permite mantener separadas las diferentes áreas del sitio y facilita el mantenimiento y crecimiento de la plataforma.
